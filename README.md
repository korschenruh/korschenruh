# Демо-лендинг усадьбы

Одностраничный сайт **по структуре** [Korschenruh](https://yuzz38.github.io/korschenruh-/), но в **другом оформлении**:

| Оригинал (Korschenruh) | Текущее демо |
|------------------------|--------------|
| Тёмно-зелёный, гирлянды, золото | Тёмный «midnight luxe»: чёрный фон, золотые линии, Cormorant + Onest |
| Дом-маска в hero | Фото со скошенной рамкой (clip-path) |
| Тот же набор блоков | Без изменений по структуре |

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `script.js` — меню, вкладки сезонов, простой калькулятор цены

## Запуск локально

Откройте `index.html` в браузере или:

```bash
npx --yes serve .
```

## GitHub Pages

1. Создайте репозиторий и залейте эти три файла в корень (или в ветку `gh-pages`).
2. В Settings → Pages выберите источник (ветка `main`, папка `/`).
3. Сайт будет по адресу `https://<user>.github.io/<repo>/`.

## Что подставить под себя

- Название, тексты, телефоны, Telegram
- Свои фото вместо Unsplash
- Полное меню кухни (в оригинале — очень длинный блок)
- Реальные отзывы и метатеги для SEO
